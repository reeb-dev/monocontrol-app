## 🎓 Glosario

| Término | Significado |
|---------|-------------|
| **Firebase** | Plataforma de Google para apps (backend as a service) |
| **Authentication** | Servicio de autenticación de Firebase |
| **Email/Password** | Método de login con email y contraseña |
| **google-services.json** | Archivo de configuración de Firebase para Android |
| **AuthRepository** | Clase que maneja la lógica de autenticación |
| **Sign up** | Registro de nuevo usuario |
| **Sign in** | Inicio de sesión |
| **Logout** | Cerrar sesión |
| **JWT** | JSON Web Token (token de autenticación) |
| **OAuth 2.0** | Protocolo de autorización estándar |

### Debugging
Si tienes problemas, revisa en orden:

1. **CHECKLIST_FIREBASE.txt** - ¿Qué está hecho?
2. **PASOS_FINALES_FIREBASE.md** - ¿Qué falta?
3. **FIREBASE_STATUS.txt** - ¿Cuál es el estado?
4. Sección "Solución de problemas" en cualquier guía

### Comandos útiles
```bash
# Ver estado de compilación
./gradlew :app:compileDebugKotlin

# Instalar la app
./gradlew :app:installDebug

# Limpiar build
./gradlew clean

# Procesar google-services.json
./gradlew :app:processDebugGoogleServices
```
